## How it is calculated
On-hand = **produced − invoiced, at the same plant**. Each plant is its own stock pool:

```
Plant X production batches (oldest → newest)
      │  Plant X invoices take the OLDEST batches first (FIFO)
      ▼
what is left = on-hand at Plant X → aged (19-Oct − production date) → bucketed
```

- A Tapi invoice can only use up Tapi's batches — it never "ships" Hyderabad's old stock. This is why plant-wise matters: pooling all plants hides which floor the old steel is on.
- A SKU = type + IS standard + size + thickness (the app's own netting key), so variant ERP codes for the same pipe net together.
- Tonnage is drained by **weight**, so on-hand equals the app's Inventory (T) figures.
- Buckets: **0–30 / 31–60 / 61–90 / 90+ days**.

## Notes and limits
- **Invoice history starts later for 3 plants.** Hyderabad's invoices go back to 31-Mar-2026; Lepakshi, NPMD and Tapi only from 30/31-Aug-2026. Tapi recorded **264.7 MT** of production before 30-Aug (NPMD 54.6 MT). If any of that was invoiced before 30-Aug, it is not in the system, so Tapi's on-hand could be **overstated by up to 264.7 MT** — and FIFO would wrongly show that overstated amount as fresh stock. Worth a physical check at Tapi.
- **Max age is capped by when tracking started** — Hyderabad 28-Mar-2026 (max ~205 days), Tapi 29-Jun, NPMD 25-Aug, Lepakshi 30-Aug.
- **Every row has a plant** — 0 production rows and 0 invoice lines are unattributed, and every SKU code resolves to the SKU master.
- **Verified two ways:** (1) the app's own `skuAgeing` + `producedPool` functions from `src/lib/calc.js`, run once per plant; (2) an independent SQL FIFO (`scripts/sku-ageing-by-plant.sql`). Both give the same on-hand and buckets per plant to 0.1 MT. Per plant, Σ buckets = on-hand, and on-hand − over-invoiced = produced − invoiced, both exactly.
- **"Made at", not "held at".** Stock is counted at the plant that produced it. A pipe moved between plants after production is not tracked.
- Reproduce: `scripts/sku-ageing-by-plant.sql` (set `as_of` at the top).
