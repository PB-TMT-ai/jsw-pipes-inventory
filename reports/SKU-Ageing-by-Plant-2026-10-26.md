## How it is calculated
Same method as last week. On-hand = **produced − invoiced, at the same plant**:

```
Plant X production batches (oldest → newest)
      │  Plant X invoices take the OLDEST batches first (FIFO)
      ▼
what is left = on-hand at Plant X → aged (26-Oct − production date) → bucketed
```

- A SKU = type + IS standard + size + thickness, so variant ERP codes for the same pipe net together. Tonnage is drained by **weight**, so on-hand matches the app's Inventory (T).
- "Invoiced from it since" = last week's over-30-day stock minus what is still left of those same batches today. Under FIFO, an invoice for a size always takes its oldest batches first, so this is exact.
- Buckets: **0–30 / 31–60 / 61–90 / 90+ days**.
